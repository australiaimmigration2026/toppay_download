# Toppay website

A public landing page that introduces the Toppay Android app, explains its main services and setup, and links directly to the APK attached to the GitHub v1.1.2 release.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build for production

```bash
npm run build
npm run start
```

When a new Android release is ready, update the release URL and version shown in `app/page.tsx`.
